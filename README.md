💰 Expense Tracker

A simple Expense Tracker built using Python. This project allows users to add expenses, view all expenses, calculate total spending, and check their spending against a given budget.

📌 Features

➕ Add a new expense

📋 View all recorded expenses

💵 Calculate total expenses

🏦 Check expenses against a budget

❌ Exit the application

✅ Basic validation to prevent negative or zero expenses

🛠️ Technologies Used

Python 3

Python Lists

Python Dictionaries

Functions

Loops

Conditional Statements

User Input

🚀 How to Run
1. Install Python

Make sure Python 3 is installed on your computer.

You can check by running:

python --version

2. Clone the Repository
```python
git clone https://github.com/Sunaina4117/Expense-Tracker-Simple-Python.git
```

4. Navigate to the Project Folder
cd expense-tracker

5. Run the Program
python expense_tracker.py

🎯 How to Use

After running the program, you will see the following menu:

===== EXPENSE TRACKER =====
1. Add Expense
2. View Expenses
3. Total Expense
4. Check Budget
5. Exit

1. Add Expense

Select 1 to add an expense.

Example:

Enter category: Food
Enter amount: 250
Expense added successfully!

2. View Expenses

Select 2 to view all recorded expenses.

Example:

Food - 250.0
Transport - 100.0
Shopping - 500.0

3. Total Expense

Select 3 to calculate the total amount spent.

Example:

Total Expense: 850.0

4. Check Budget

Select 4 and enter your budget.

Example:

Enter your budget: 1000
Remaining Budget: 150.0


If the expenses exceed the budget:

Budget exceeded by: 200.0

5. Exit

Select 5 to exit the application.

======Thank you======

🧠 Concepts Used

This project demonstrates several fundamental Python concepts:

Lists – Used to store multiple expenses.

Dictionaries – Used to store expense details such as category and amount.

Functions – Used to organize different operations.

Loops – Used for displaying and calculating expenses.

Conditional Statements – Used for validation and menu selection.

User Input – Used to interact with the application.

⚠️ Limitations

Expenses are stored only while the program is running.

Data is lost when the program is closed.

There is no database or file storage.

Invalid non-numeric input may cause an error.

The application currently supports a single budget check at a time.
